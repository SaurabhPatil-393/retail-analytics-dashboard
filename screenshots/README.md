# Screenshots

This folder is where the dashboard screenshot referenced in the main `README.md` should live.

A real screenshot wasn't generated automatically as part of this build (headless browser
rendering wasn't available in the build environment), so add one after you deploy:

1. Open your live dashboard (or `index.html` locally) in a desktop browser.
2. Resize the window to a normal desktop width (e.g. 1440px wide) for a clean shot.
3. Take a screenshot of the Overview tab (Windows: `Win+Shift+S`, Mac: `Cmd+Shift+4`).
4. Save it into this folder as `dashboard.png`.
5. Commit and push it — the image referenced in `README.md` (`screenshots/dashboard.png`) will
   then render on the GitHub repo page automatically.

Optional: add a couple more, e.g. `dashboard-products.png`, `dashboard-mobile.png`, and reference
them in the README if you'd like a small gallery.
